↳ ClassGPT drag this to your bookmarks bar

  1. Show your bookmarks bar

    Ctrl/Cmd + Shift + B in Chrome, Edge, or Firefox, if it isn't already showing.

  2. Drag the ClassGPT button up there

    It's a real link — drag it straight into the bookmarks bar. On phones, use the browser's "add bookmark" flow and paste the code from the box below instead.

  3. Click it on any site

    If you baked in a key above, it opens straight into the chat, ready to go, every time. Click the bookmark again (or Ctrl+Shift+G, if that's on) to show or hide it without losing your chat.

  4. Explore the icons in the header

    📁 switches between saved threads, ⚙ opens settings (model, features), ✕ closes. Inside the message box, 📄 reads the page or your current selection, 🌐 translates whatever's selected, and 🎤 is voice input.

What's in it

Multiple threadsKeep separate conversations per topic and switch between them from the 📁 icon.
Pin messagesPin any message so it stays visible in a bar above the chat as it scrolls.
RegenerateNot happy with a reply? Regenerate it in place without retyping your question.
Read page or selection📄 reads your current text selection if you have one, otherwise the whole page.
Image inputPaste or drag an image into the chat and ask about it (needs a vision-capable model).
Translate selection🌐 detects the language of whatever's selected and translates it to your browser's language.
Model pickerDropdown of presets or a custom model id. Defaults to GPT-4o mini.
Markdown, cost estimate, voice input, export, insert-into-pageAll toggleable from settings.
